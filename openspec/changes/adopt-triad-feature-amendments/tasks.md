# Governance and Handoff Checklist

This is the governance checklist. Speckit owns the executable implementation tasks; this file does not duplicate them.

## 1. Capture and adoption

- [x] 1.1 Capture the rationale in a linked brainstorm packet and record the user's adoption in a separate operating document; verify the packet and its links.
- [x] 1.2 Define amendment records, scope classification, final reconciliation and project landing requirements; verify the capability delta with strict OpenSpec validation.
- [x] 1.3 Apply the adopted manual default to the installed shared protocol and record documentation verification evidence.

## 2. Implementation handoff

- [ ] 2.1 Hand this change to one Speckit feature for automation, with workBenches protocol distribution/root guidance and an explicit upstream openRepoShape placement dependency; verify the handoff names the feature and its sole executable task file.

## 3. Qualification and archival

- [ ] 3.1 Confirm the qualified schema, routing, placement exception and reconciliation behavior through the Speckit evidence before claiming automated delivery.
- [ ] 3.2 Archive only after the corresponding implementation and project landing have completed, or record explicit abandonment; verify landed references and preserved history.
