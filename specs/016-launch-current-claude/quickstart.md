# Quickstart: Verify launching the newest published Claude Code

1. From the feature worktree, run the launcher suites against the worktree launcher: `bash devcontainer.test/test-claude-profile-binary-selection.sh base-image/files/claude-profile`, then each claude-profile suite `devcontainer.test/test.sh` lists (lane default, `--lane` hand-off, SessionStart hook, name guard), with both `claude-profile` and `lclaude` where it lists both. Also run `test-claude-profile-amendment-11.sh` and `test-claude-profile-skill-install.sh`, which `.github/workflows/speckit-git-bash.yml` runs beside the binary-selection suite, and `test-claude-profile-preserves-model.sh` and `test-claude-usage-guard-auto-swap.sh`.
2. Confirm the binary-selection suite prints `claude-current resolution: N checks passed`. Its stub resolver covers verified, ahead, unverified, stale refused, stale allowed, no candidate, a resolver outside its contract, a pin, an inherited pair, offline commands, the `lane-start` hand-off, a refused hand-off, the tmux-wrapped launch, and no resolver at all.
3. Run the status line suites: `bash devcontainer.test/test-claude-tmux-statusline.sh base-image/files/claude-profile base-image/files/claude-statusline-command.sh`, its env-isolation wrapper with the same arguments, and `bash devcontainer.test/test-claude-statusline-snapshots.sh base-image/files/claude-statusline-command.sh`.
4. Run the Layer 3 suites: `test-ai-cli-install-summary.sh`, `test-layer3-codex-version.sh`, `test-layer3-claude-version.sh` and `test-ensure-layer3-freshness.sh` under `devcontainer.test/`, as `.github/workflows/ai-cli-layer3.yml` does.
5. Optional, with Docker: build a disposable image with `user-layer/build.sh --base workbench-base:latest --user <name>`. Check that `claude` resolves under `$HOME/.npm-global/bin` at npm's latest version, and that the base image's copy is still present, root-owned and runnable. Then remove the tag.
6. Against the real commands: install `opensoft/openRepoTools` (#134) with `openRepoTools --install`, then start `pclaude <profile>`. The first stderr line reads `claude-current: claude <version> (verified against npm <published>) at <path>`.
7. Deploy only through the normal image or bench synchronization path. A source edit does not update a running container: every running session keeps its binary until the operator restarts it, and the status line says when it should.
