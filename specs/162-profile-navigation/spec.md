# Hierarchical profiles (v1.6.2 development)

Authority: Brett's 2026-10-27 navigation request and browser-connected export
clarification. Governed by `hierarchical-profile-navigation`.

Use the 1.7 stacked list/About pattern in the Bash Profile pane and Python
profile lists/editors. Personal profiles are existing personal identities;
companies retain their existing company IDs and email identities. New optional
local-workstation records and per-profile descriptions/source locators preserve
version-2 readers. Existing personal AI ownership stays with its original
default identity; additional personal profiles receive independent stable IDs.

Supported model makers reflect the existing provider integrations (Anthropic,
OpenAI, Google, xAI and Z.ai). Makers and account lists include import/add
actions. Neither navigation nor export authenticates an AI provider.

Profile locations support local JSON, public HTTPS, selected-account GitHub
and connected Google Drive/OneDrive. Explicit export uses the saved connection,
checks reviewed remote content and offers local files for HTTPS. Portable
metadata cannot replace IDs, GitHub credentials or company sign-in state.

Cancellation, malformed files, denied uploads and conflicts preserve existing
profiles and credentials. Verify disposable metadata, two-owner isolation,
navigation by PTY, narrow terminals and GitHub/Drive fixture uploads. Production
cloud consent/upload remains attended acceptance, not inferred from fixtures.
