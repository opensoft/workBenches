# Analysis

The existing personal collection contains multiple identities sharing one AI
scope; navigation must not simply relabel these as independent profiles. Pin
the legacy scope to the existing default identity and assign new stable scopes
to the others. Keep companies' existing paths untouched. Local workstation
presets do not introduce remote workstation access. Browser source login,
company sign-in and provider credential recovery remain separate authorities.

GitHub's file SHA gives a conditional update. Rclone Drive has a preflight
content check, not an atomic compare-and-swap; document the remaining race.
